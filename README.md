# Smart Assisted-Care Hospital Bed with Automated Toileting and Patient Monitoring

A serious virtual mechatronics engineering project focused on continuous patient monitoring, assisted defecation, automated waste removal, sanitation control, safety interlocks, accessibility, and caregiver support.

## Project status
Day 1 — Engineering foundation and patient-monitoring input chain.

## Main toolchain
- Wokwi
- Arduino Mega 2560 / Arduino C++
- VS Code
- Git/GitHub
- MATLAB
- Simulink

## Important scope note
This repository represents an engineering simulation/prototype. It is not a clinically validated medical device.
