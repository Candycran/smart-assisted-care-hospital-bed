# Smart Assisted-Care Hospital Bed — Day 3

## Focus
Assisted-toileting mechanical control and safety logic.

Day 3 adds:
- toilet request button;
- emergency button;
- patient-presence input;
- obstruction input;
- open-position limit input;
- closed-position limit input;
- toilet-access servo;
- READY and FAULT LEDs;
- buzzer;
- non-blocking state-machine control;
- open/close position feedback;
- double-press finish command;
- fault and emergency handling.

## Scope boundary
Day 3 ends with the toilet mechanism safely SECURED after use.
Waste evacuation, flushing, rinsing, drainage and self-cleaning belong to Day 4.

## Important
This is an engineering simulation/prototype and is not a clinically validated medical device.
