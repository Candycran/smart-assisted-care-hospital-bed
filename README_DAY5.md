# Day 5 — Final Integration, Verification and Engineering Closeout

Day 5 is the final development day for the virtual Smart Assisted-Care Hospital Bed.

## Final-day objectives
1. Freeze the hardware architecture.
2. Add a controlled caregiver RESET/ACKNOWLEDGE input.
3. Run full end-to-end and regression tests.
4. Complete preliminary FMEA/risk analysis.
5. Complete requirements-to-test traceability.
6. Consolidate Wokwi, MATLAB and Simulink evidence.
7. Capture professional screenshots/GIFs.
8. Clean and finalise the GitHub repository.

No new functional subsystem should be introduced after Day 5.

## Final prototype scope
- simulated multi-parameter patient monitoring;
- assisted defecation request and access control;
- occupancy and obstruction safety logic;
- open/closed position feedback;
- emergency handling;
- double-press patient completion command;
- waste evacuation;
- automatic flush/rinse/drain cycle;
- water/drain/leak safety monitoring;
- sanitation-cycle verification;
- caregiver fault/emergency recovery;
- MATLAB analysis;
- Simulink actuator model;
- documented verification and preliminary risk analysis.

This is an educational virtual engineering prototype, not a clinically validated medical device.
