# Day 1 Notes

## Day 1 objective
Build the project foundation carefully and prove the first complete sensing path:

simulated physiological input -> Arduino Mega ADC -> software conversion -> Serial Monitor output

## First signal
Heart rate is the first signal because it is easy to understand and lets us learn:
- analogue input
- potentiometer wiring
- ADC values
- mapping
- Serial Monitor
- clean Wokwi layout

## Rule
Do not add the next subsystem until the current subsystem is understood and tested.
