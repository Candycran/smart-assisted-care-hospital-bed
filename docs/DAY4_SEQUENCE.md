# Day 4 Sanitation Sequence

SECURED -> SANITATION_CHECK -> WASTE_EVACUATION -> PRIMARY_FLUSH -> DRAIN_1 -> RINSE_1 -> DRAIN_2 -> FINAL_RINSE -> FINAL_DRAIN -> CYCLE_VERIFY -> SANITATION_COMPLETE -> NORMAL

## Demonstration timings
- Waste evacuation: 3.0 s
- Primary flush: 4.0 s
- Drain 1: 2.5 s
- Rinse 1: 4.0 s
- Drain 2: 2.5 s
- Final rinse: 3.0 s
- Final drain: 3.0 s
- Cycle verify: 1.5 s
- Completion hold: 1.5 s

These are control-simulation values, not clinically validated sanitation timings.
