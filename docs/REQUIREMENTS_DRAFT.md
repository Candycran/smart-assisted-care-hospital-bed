# Requirements Draft

## System purpose
Develop a virtual mechatronics prototype of a smart assisted-care hospital bed for mobility-impaired patients.

## Core functional areas
- Continuous patient monitoring
- Accessible patient controls
- Assisted defecation
- Automated waste evacuation
- Automated bowl sanitation
- Emergency/caregiver alerting
- Safety interlocks and fault handling

## Current Day 1 boundary
Patient-monitoring input chain only. No toilet mechanism is added until the monitoring foundation is understood.
